Goal

To master the algebraic manipulation of trigonometric functions to prove identities and solve complex equations.

Equation vs. Identity

Equation

sin(x) = 1/2
  • Only true for specific values of x.
  • Goal: Solve for x.
  • (e.g., x = π/6, 5π/6)

Identity

sin2x + cos2x = 1
  • True for ALL values of x.
  • Goal: Prove Left Side = Right Side.
  • (Cannot solve for x, because x is infinite!)

Warm-up: Grade 11 Foundations

Before proving Grade 12 identities, you must recall the Grade 11 basics.

Quotient Identity

tan(x) = sin(x) / cos(x)

Reciprocal Identities

csc(x) = 1 / sin(x)

sec(x) = 1 / cos(x)

cot(x) = cos(x) / sin(x)

Pythagorean Identity

sin2x + cos2x = 1

Also: sin2x = 1 - cos2x

Equivalent Trig Expressions

Trig functions are Periodic.

Because they repeat forever, shifting the graph by a full cycle (2π) lands you back on the exact same value.

sin(x) = sin(x ± 2π)

cos(x) = cos(x ± 2π)

tan(x) = tan(x ± π)

*Tangent repeats every π, not 2π.

Co-function Identities

What is the relationship between Sine and Cosine?

They are the exact same wave, just shifted left or right by π/2 (90°).

  • sin(x) = cos(x - π/2)
  • cos(x) = sin(x + π/2)

The Compound Angle Formulas

How do we find the exact value of cos(7π/12)?

7π/12 is not on our special triangles. But, we can break it apart into two angles that ARE on our triangles!

7π/12 = 3π/12 + 4π/12 = π/4 + π/3

To evaluate this, we need formulas that allow us to add angles INSIDE a trig function: f(a + b).

Compound Formulas: Cosine

Memory Trick: "Cosine is Cliquey and Contrary"
The cosines group together, the sines group together, and the sign flips!

cos(a + b) = cos(a)cos(b) - sin(a)sin(b)
cos(a - b) = cos(a)cos(b) + sin(a)sin(b)

Compound Formulas: Sine

Memory Trick: "Sine is Social and Same"
Sine mixes with cosine, and the sign stays exactly the same!

sin(a + b) = sin(a)cos(b) + cos(a)sin(b)
sin(a - b) = sin(a)cos(b) - cos(a)sin(b)

Compound Formulas: Tangent

Tangent creates a fraction.
The TOP matches the original sign. The BOTTOM is opposite.

tan(a + b) = (tan a + tan b) / (1 - tan a tan b)
tan(a - b) = (tan a - tan b) / (1 + tan a tan b)

Practice: Exact Values

Find the exact value of: sin(5π/12)

Step 1: Break the angle apart.
5π/12 = 2π/12 + 3π/12 = π/6 + π/4

Step 2: Set up the formula. (Sine is "Social and Same")
sin(π/6)cos(π/4) + cos(π/6)sin(π/4)

Step 3: Plug in Special Triangle values.
(1/2)(√2/2) + (√3/2)(√2/2)

Answer = (√2 + √6) / 4

Double Angle Formulas

What happens if angles 'a' and 'b' are the exact same angle? sin(x + x)

The compound formulas condense perfectly into the Double Angle Formulas.

  • sin(2x) = 2 sin(x)cos(x)
  • tan(2x) = 2 tan(x) / (1 - tan2x)

What about Cosine?

Cosine is special.

Because cos(x+x) = cos(x)cos(x) - sin(x)sin(x)...

cos(2x) = cos2x - sin2x

The 3 Faces of Cos(2x)

Using the Pythagorean identity (sin2x + cos2x = 1), we can rewrite cos(2x) in three different ways. You must memorize these for proofs!

1. The Standard

cos2x - sin2x

2. Cosine Only

2cos2x - 1

3. Sine Only

1 - 2sin2x

Practice: Double Angle Expansion

Condense and evaluate the exact value of:

2 sin(π/8) cos(π/8)

Notice the pattern: 2 sin(x) cos(x) = sin(2x)

Here, x = π/8.

→ sin( 2 * π/8 )

→ sin( π/4 )

Answer = 1 / √2

Proving Identities: The Golden Rules

Proving an identity is NOT solving an equation. You are trying to prove that LHS = RHS.

  • Rule 1: NEVER cross the line. You cannot move terms from left to right. Work on one side independently.
  • Rule 2: Start Messy. Pick the ugliest, most complicated side to simplify.
  • Rule 3: Convert. When in doubt, change everything to sine and cosine.

The Fatal Error

If you multiply both sides by the same thing, or square both sides, you get ZERO MARKS.

Identity Proof: Example 1

Prove: tan(x) + cot(x) = sec(x)csc(x)

Left Hand Side (LHS)

tan(x) + cot(x)

= (sin x / cos x) + (cos x / sin x) // Convert

= (sin2x + cos2x) / (sin x cos x) // LCD

= 1 / (sin x cos x) // Pythagorean!

= (1 / cos x)(1 / sin x)

= sec(x)csc(x)

Right Hand Side (RHS)

sec(x)csc(x)

LHS = RHS

Q.E.D.

Identity Proof: Example 2 (Double Angles)

Prove: sin(2x) / (1 + cos 2x) = tan(x)

Left Hand Side (LHS)

sin(2x) / (1 + cos 2x)

Top must become 2 sin x cos x.

For the bottom, pick the version of cos(2x) that cancels out the '1': 2 cos2x - 1.

= (2 sin x cos x) / (1 + 2 cos2x - 1)

= (2 sin x cos x) / (2 cos2x)

= (sin x) / (cos x) // Cancel the 2 and one cos(x)

= tan(x)

Solving Trig Equations: Linear Review

Switching back to Equations. Our goal is to solve for x in the domain 0 ≤ x ≤ 2π.

2 sin(x) - 1 = 0

  • Step 1: Isolate the trig ratio. (sin x = 1/2)
  • Step 2: Use CAST rule to find quadrants. (Q1 and Q2)
  • Step 3: Use special triangles for ref angle. (π/6)

x = π/6, 5π/6

Solving Trig Equations: Quadratic

What if there is a squared term? Factor it exactly like Grade 10 math!

2 sin2x - sin x - 1 = 0

Treat sin(x) like a giant 'A'.

2A2 - A - 1 = 0

Factor the quadratic:

(2A + 1)(A - 1) = 0

The Two Branches

Replace 'A' back with sin(x):

(2 sin x + 1)(sin x - 1) = 0

This splits into two linear equations:

  • sin x = -1/2
  • sin x = 1

Worked Example: Quadratic Trig Eq

Solving: (2 sin x + 1)(sin x - 1) = 0 for 0 ≤ x ≤ 2π

Branch 1: sin x = -1/2

  • Sine is negative in Q3 and Q4.
  • Reference angle is π/6.
  • Q3: π + π/6 = 7π/6
  • Q4: 2π - π/6 = 11π/6

Branch 2: sin x = 1

  • Where on the unit circle is the y-coordinate exactly +1?
  • Right at the top!
  • x = π/2

Solution: x ∈ { π/2, 7π/6, 11π/6 }

Solving Equations with Double Angles

The Ultimate Trap

cos(2x) + cos(x) = 0

You CANNOT factor this right now because the angles don't match! One is '2x', the other is 'x'.

Step 1: Use a Double Angle Formula to swap out cos(2x). Choose the one that only has cosine: 2 cos2x - 1

Step 2: Substitute. → (2 cos2x - 1) + cos(x) = 0

Step 3: Rearrange into a standard quadratic. → 2 cos2x + cos x - 1 = 0

Now you can factor and solve!

The Extraneous Root Trap

Solve: sin(x)cos(x) = sin(x)

Fatal Error

Dividing both sides by sin(x) to get cos(x) = 1. You just deleted half your answers!

The Correct Way

Move everything to one side and common factor!

sin(x)cos(x) - sin(x) = 0

sin(x) [ cos(x) - 1 ] = 0

Now you have two valid branches:

  • sin(x) = 0
  • cos(x) = 1
