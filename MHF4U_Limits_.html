Topic 1: Core Concept

What is a Limit?

Intuition and Mathematical Definition

A limit describes the value that a function's output approaches as the independent input variable gets arbitrarily close to a target number.

limx → a f(x) = L
  • We read this as: "The limit of f(x) as x approaches a equals L."
  • Fundamental distinction: A limit cares about the behavior of f(x) near a, not necessarily at x = a.
  • f(a) might be undefined, yet the limit can still exist as a finite real number.
Topic 1: Core Concept

Archimedes' Method of Exhaustion

The Ancient Roots of Limits

To prove that the area of a circle is A = πr2, Archimedes inscribed regular polygons inside a circle.

  • 4-sided polygon (square): coarse approximation.
  • 8-sided polygon (octagon): much closer fit.
  • 10,000-sided polygon (myriagon): almost identical.

As the number of sides approaches infinity (n → ∞), the area of the polygon approaches the area of the circle as its limiting value.

Topic 1: Core Concept

One-Sided Limits

Left-Hand and Right-Hand Behavior

Values can approach a point from numbers smaller (left) or larger (right).

Left-Hand Limit (LHL)

limx → a- f(x)

x approaches a strictly from values smaller than a (from the negative direction / left side of number line).

Right-Hand Limit (RHL)

limx → a+ f(x)

x approaches a strictly from values larger than a (from the positive direction / right side of number line).

Topic 1: Core Concept

Criteria for Limit Existence

The Three Necessary Conditions

The two-sided limit limx → a f(x) = L exists if and only if:

  1. Left-hand limit exists: limx → a- f(x) = L1 (where L1 is a real number).
  2. Right-hand limit exists: limx → a+ f(x) = L2 (where L2 is a real number).
  3. The two one-sided limits are equal: L1 = L2 = L.

Key Insight: If the left and right approaches settle on different values, or if either side diverges to infinity, the two-sided limit does not exist (DNE).

Vertical Asymptotes as Infinite Limits

Rational Graph f(x) = (x + 1) / (x - 4)

At x = 4, the denominator becomes 0 while the numerator is 5. This generates a Vertical Asymptote.

  • As x approaches 4 from the left (x → 4-, e.g. 3.999):
    (+5) / (-0.001) → -∞
  • As x approaches 4 from the right (x → 4+, e.g. 4.001):
    (+5) / (+0.001) → +∞

Because the values grow without bound and disagree in direction, limx → 4 f(x) does not exist.

Topic 2: Visualizing Limits

Horizontal Asymptotes (Limits at Infinity)

End Behavior of Rational Functions

A Horizontal Asymptote represents the limit of the function as x increases or decreases without bound:

limx → ∞ f(x) = L    and    limx → -∞ f(x) = L

Rule of Leading Coefficients: For f(x) = (axn + ...) / (bxn + ...) where the numerator and denominator have equal degrees:

Horizontal Asymptote: y = a / b

For f(x) = (x + 1)/(x - 4): limx → ±∞ f(x) = 1/1 = 1.

Topic 3: Algebraic Limits

Strategy 1: Direct Substitution

First Step

Always attempt direct substitution first. If a function is continuous at x = a, the limit is simply the function's value:

limx → a f(x) = f(a)

Direct substitution works for all polynomials everywhere, and for rational functions provided the denominator is non-zero.

Example: Direct Substitution

limx → 2 [3x / (x2 + 2)] = [3(2)] / [22 + 2] = 6 / 6 = 1

Because the denominator does not evaluate to 0, 1 is the exact value of the limit.

Topic 3: Algebraic Limits

The Indeterminate Form 0 / 0

When Substitution Breaks Down

When direct substitution produces 0 / 0, this is an indeterminate form.

  • 0/0 does not mean the limit is undefined.
  • 0/0 does not mean the limit is 0.
  • It means: "A common factor of (x - a) exists in both the numerator and denominator, hiding a removable discontinuity (hole)."

Goal: Factor algebraic expressions, cancel the common factor (x - a), and re-evaluate by direct substitution.

Topic 3: Algebraic Limits

Factoring: Difference of Squares

Factoring Example: Difference of Squares

Evaluate: limx → 2 [(4 - x2) / (2 - x)]

  1. Direct substitution: (4 - 4)/(2 - 2) = 0/0 (Indeterminate).
  2. Factor numerator: (4 - x2) = (2 - x)(2 + x).
  3. Cancel common factor: limx → 2 (2 + x).
  4. Direct substitution: 2 + 2 = 4.

On a graph, this function is the straight line y = x + 2 with a single removable hole at (2, 4).

Topic 3: Algebraic Limits

Difference & Sum of Cubes Formulas

Factoring Formulas

In Grade 12 Advanced Functions, sum and difference of cubes frequently appear in limit questions:

Difference of Cubes

a3 - b3 = (a - b)(a2 + ab + b2)

Example: x3 - 27 = (x - 3)(x2 + 3x + 9)

Sum of Cubes

a3 + b3 = (a + b)(a2 - ab + b2)

Example: x3 + 64 = (x + 4)(x2 - 4x + 16)

Mnemonic SOAP for the signs: Same, Opposite, Always Positive.

Rates of Change: Secants vs Tangents

Bridging Algebra to Calculus

Average Rate of Change (AROC)

  • Calculated across an interval between two distinct points [x1, x2].
  • Represented by the slope of a Secant Line cutting through the curve.
  • Formula: msec = Δy / Δx

Instantaneous Rate of Change (IROC)

  • Calculated at one single, frozen moment x = a.
  • Represented by the slope of a Tangent Line skimming the curve at that single point.
  • Formula: mtan = limh → 0 [f(a + h) - f(a)] / h
Rates of Change (If Time Allows)

The Secant-to-Tangent Limit Process

A Limit Connection

How do we find a slope with only one point? We use a limit:

  1. Pick our point of interest: (a, f(a)).
  2. Pick a second point nearby: (a + h, f(a + h)).
  3. Secant slope: m = [f(a + h) - f(a)] / h.
  4. Now, let the distance h shrink to zero: h → 0.

As h → 0, the secant line rotates until it becomes the tangent line.

Rates of Change (If Time Allows)

The Newton Difference Quotient

Derivative Formula

The exact instantaneous rate of change (derivative) is formulated as:

mtan = limh → 0 [f(a + h) - f(a)] / h

Notice the connection to limits:

If you substitute h = 0 directly: [f(a + 0) - f(a)] / 0 = 0 / 0 (the indeterminate form!).

Every single derivative in calculus is simply an algebraic limit of the indeterminate form 0/0.

Worked Example: IROC via Difference Quotient

Find the slope of f(x) = x2 at x = 3

Step 1: Setup Difference Quotient with a = 3:

limh → 0 [f(3 + h) - f(3)] / h

Step 2: Expand f(3 + h) and f(3):

= limh → 0 [(3 + h)2 - 32] / h
= limh → 0 [9 + 6h + h2 - 9] / h

Step 3: Simplify and factor out h:

= limh → 0 [6h + h2] / h = limh → 0 [h(6 + h)] / h = limh → 0 (6 + h)

Step 4: Evaluate the limit as h → 0: 6 + 0 = 6.

What is the exact instantaneous rate of change at x = 1?

g(1 + h) = (1 + h)2 + 2(1 + h) = 1 + 2h + h2 + 2 + 2h = h2 + 4h + 3.
g(1 + h) - g(1) = h2 + 4h + 3 - 3 = h2 + 4h.
Divide by h: h + 4.

Numerical Estimation of IROC (h = 0.001)

Using a Small Interval

In MHF4U, when an algebraic limit is too cumbersome or a table is given, we approximate the limit with a tiny step h = 0.001:

IROC ≈ [f(a + 0.001) - f(a)] / 0.001

Example for f(x) = 1/x at x = 2:

  • f(2) = 0.5
  • f(2.001) = 1 / 2.001 ≈ 0.4997501
  • IROC ≈ (0.4997501 - 0.5) / 0.001 = -0.0002499 / 0.001 ≈ -0.25 = -1/4.

Physical Application: Instantaneous Velocity

Motion Under Gravity

A ball is thrown upward. Its height in meters after t seconds is modeled by:

s(t) = -4.9t2 + 20t + 2
  • Position: s(t)
  • Average Velocity: AROC = [s(t2) - s(t1)] / (t2 - t1)
  • Instantaneous Velocity: v(a) = limh → 0 [s(a + h) - s(a)] / h

A positive velocity means the object is moving upward; a negative velocity means downward motion; zero velocity indicates the peak (turning point).

Practice

Using the limit formula: v(2) = limh → 0 [s(2 + h) - s(2)] / h.

Active Check: Compute Velocity

Enter the instantaneous velocity in m/s at t = 2:

v(t) = s'(t) = -9.8t + 20.
At t = 2: v(2) = -9.8(2) + 20 = -19.6 + 20 = 0.4 m/s.
Since v(2) > 0, the ball is still rising, very close to its maximum height.

Equation of the Tangent Line

Full Two-Step Procedure

To find the equation of a line tangent to y = f(x) at x = a:

  1. Find the slope (m): Calculate the instantaneous rate of change using the limit: m = limh → 0 [f(a + h) - f(a)] / h.
  2. Find the point: The point is (a, f(a)).
  3. Assemble the equation: Use point-slope form: y - f(a) = m(x - a).
Example: For f(x) = x2 at x = 3 → m = 6, Point = (3, 9) → y - 9 = 6(x - 3) → y = 6x - 9

Review

Common Errors to Avoid

Top 4 Pitfalls to Avoid

1. Dropping Limit Notation

Do not drop the prefix limx → a until you actually perform the final substitution step. Marks are deducted for missing notation.

2. Confusing 0/0 with 0/k

0/0 is indeterminate (needs work). 0/5 is simply 0 (you are already done!).

3. One-Sided Limit Inconsistency

If LHL = 2 and RHL = -2, the two-sided limit is DNE. Never average them.

4. Difference of Cubes Signs

Remember SOAP: (a - b)(a2 + ab + b2). There is no "2ab" in the middle term!
